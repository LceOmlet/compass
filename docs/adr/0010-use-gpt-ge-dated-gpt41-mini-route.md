# Use one dated GPT-4.1 Mini route for the primary panel

All primary task and reflection calls use the OpenAI-compatible `https://api.gpt.ge/v1` route with model alias `gpt-4.1-mini-2025-04-14`; text and structured-image probes verified that the endpoint resolves that dated model.  The common profile freezes chat mode, temperature `1.0`, output cap `16384`, disabled thinking, and DSPy `num_retries=0`.  Every benchmark--method run activates a distinct disk and memory cache through DSPy's official `configure_cache` interface before LM construction, so pilots, baselines, and COMPASS do not share cached generations.  Shared-route TPM/429 keepalive remains within the original logical call and never increments the logical-rollout budget.  Source-controlled configs name only `COMPASS_GPT_GE_API_KEY`, while the authorized credential remains in a local user-bound encrypted store, so no method receives a different provider route and no plaintext key enters source, manifests, or logs.
