\subsection*{Ethics statement}
Evidence routing can reduce the number of expensive environment executions
needed to discover a useful textual program and can make search decisions easier
to audit.  The same efficiency can also optimize undesirable procedures or
exploit imperfect rewards.  Responsible deployment calls for secure tool
policies, sandboxing, red-team evaluation, and human review.
